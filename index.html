01 / PERSONAL FINANCEMobile application

INFAQ—

A clearer view of your finances.

A personal finance management app that brings income, expenses, budgets, subscriptions, and savings goals into one place—so everyday money decisions feel easier to understand.

The problem

Financial activity can be scattered and hard to make sense of. INFAQ brings it together with transaction tracking, budgets, and spending insights.

What it does

Track and categorize transactions, manage a monthly budget, follow recurring subscriptions and savings goals, and review financial summaries.

Technical focus

Mobile development with Flutter and Dart, Supabase and PostgreSQL for data services, and Gemini API integration for intelligent transaction categorization.

  • Flutter
  • Dart
  • Supabase
  • PostgreSQL
  • Gemini API

02 / READING & COMMUNITYMobile application

Readers—

A home for your reading life.

A reading-tracking and social app built with Flutter and Supabase. It helps users manage a personal library, save notes while they read, discover new titles, and explore what other readers are reading.

Build a reading habit

Search books and authors, discover titles through Google Books integration, and organize your shelf into Want to Read, Currently Reading, and Read.

Keep what you learn

Write, edit, and delete notes for each book so key ideas and reflections stay connected to what you read.

Read together, privately

Find readers by username and explore public libraries. Profile privacy settings let readers decide whether their library is public or private.

  • Flutter
  • Dart
  • Supabase
  • PostgreSQL
  • Google Books API
IMPLEMENTATION STACK

This project was built with Flutter for the mobile app interface and Supabase for backend services, database storage, and app data management. Google Books integration is shown in the supplied app screens.
